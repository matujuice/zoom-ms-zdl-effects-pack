# CLAUDE.md

Read this first, then the effect's header comment (each `.c` file fully describes its knobs and DSP). docs/EFFECTS.md has the user-facing detail.

## What this is
Eight custom effects (WaveFold, DualShft, Choral, EuGate, DubSiren, S.GN_L, Scrub, DirtBox) for Zoom MS pedals, built as `.ZDL` with the toolchain from themanro/ZoomMultistompZDL (`build/`). Owner's pedal: MS-60B on MS-50G firmware; other pedals untested. Effects are for synths/drums, never guitar.

## Layout

- `src/custom/<effect>/`: `<effect>.c`, `manifest_pedal.json` (knobs, ranges, defaults, fxid), `make_cover.py`, `build.py`. Choral is in `formant/`, S.GN_L in `sgnl/`.
- `src/airwindows/common/covers/*.json`: generated by `make_cover.py`, loaded by `custom_covers.py`.
- `tests/`: host tests (`python3 tests/run.py [name]`). `release/`: pack README, cover sheet; `make_release.py` zips `dist/*.ZDL`.
- fxids: DualShft 480, DubSiren 485, Choral 486, WaveFold 487, EuGate 488, S.GN_L 489, Scrub 490, DirtBox 491, Breather 493, SyncEQ 494, Sweep 496.
- `src/probes/<probe>/`: hardware probes, never released, built only when named (TempoPrb, fxid 499).
- S.GN_L: `effect_name` SGNL (file, symbols, SONAME); `display_name` S.GN_L only in the descriptor name entry.
- Docs: `docs/SAFE-DSP-RULES.md` (C rules), `docs/DECISIONS.md` (owner decisions per effect), `docs/COVERS.md` (cover rules), `docs/TEMPO-SYNC.md`, `docs/IPHONE-SYNC.md`, `docs/EFFECTS.md`.

## Building and testing
The TI C6000 compiler is only on the owner's Windows PC; the cloud can't build `.ZDL`. The owner runs `build_<effect>.bat` and loads `dist\<Name>.ZDL` with Zoom Effect Manager. Claude handles source, manifests, covers and host tests; run `python3 tests/run.py` after any DSP change and say plainly what was and wasn't tested (no listening test, CPU never measured).

## C code rules (each caused a real failure, or see docs/SAFE-DSP-RULES.md)

- No float-to-unsigned casts (`__c6xabi_fixfu` unresolved): write `(unsigned int)(int)(x)`.
- No libm; use helpers (`wf_rsqrt`, `exp2_oct`). Avoid float division and all integer division/modulo.
- No `switch`, no static/const arrays in `.audio`, no `double`, no `long long`. Helpers are `*_ALWAYS_INLINE`.
- Never write the Dry buffer (ctx[4]) except to send the bar tag with `src/custom/common/drytag.h`; other effects pass it on by leaving it alone (docs/TEMPO-SYNC.md, "Bar tag").
- `effect_name` max 8 chars.
- Knobs arrive as (screen value)/100; convert back like `sr_knob`, `ch_ui`, `wf_knob`. Read Tempo and Scrub's Pos as raw x 100, never through the 3.05 guess.
- `ZDL_GetLabel_N` sees only its own knob; encode dependencies in the range (e.g. 101..112 = note values).
- State lives in the arena, validated by a magic number: change the magic when the struct changes.
- Keep the 8-sample block structure: knob reads and `prepare` once per block, then the sample loop.

## Conventions
- Mix = DJ crossfade (dry min(1,2-2m), wet min(1,2m)); DubSiren has Vol, no Mix.
- Tempo is knob 8 on every synced effect, runs 0..441 with twin BPM copies, 0..39 = FOLLOW (see docs/TEMPO-SYNC.md); read raw x100, then pass it through `dt_tempo()` (bar tag).
- Covers: see docs/COVERS.md. Owner decisions: see docs/DECISIONS.md (don't undo).
- Change a knob or behaviour: update header comment, manifest, docs/EFFECTS.md, README, docs/IPHONE-SYNC.md table in step.
